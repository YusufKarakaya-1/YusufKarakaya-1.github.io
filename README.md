# Yusuf Karakaya — Portfolio

Static GitHub Pages portfolio for Yusuf Karakaya.

## Structure
- `index.html` — About / landing page
- `expertise.html` — expertise and education
- `projects.html` — projects and media
- `experience.html` — work experience
- `contact.html` — contact
- `style.css` — shared styling
- `script.js` — mobile navigation
- `assets/` — CV, images, videos and PDFs

## Media
Replace the placeholders with your own files. For PDFs, add them to `assets/projects/` and update the corresponding link in `projects.html`.

A static GitHub Pages site cannot receive file uploads from visitors without a backend. “Upload” here means adding your own PDF/video/image files to the repository.
